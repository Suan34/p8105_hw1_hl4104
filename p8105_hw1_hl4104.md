By the `glimpse()` function above, we could tell that:

The `penguins` dataset contains measurements for individual penguins
observed on islands in the Palmer Archipelago and has **344 rows** and
**8 columns**. Each row represents one penguin, and each column
represents one characteristic.

The main variables are: - `species`: penguin species (Adelie, Chinstrap,
Gentoo); - `island`: island where the penguin was observed (Biscoe,
Dream, Torgersen); - `bill_length_mm` and `bill_depth_mm`: bill
measurements in millimeters; - `flipper_length_mm`: flipper length in
millimeters; - `body_mass_g`: body mass in grams; - `sex`: recorded sex
(female, male); - `year`: year of observation, from 2007 to 2009.

There are 2 missing values in `flipper_length_mm`. After excluding them
with `na.rm = TRUE`, the mean flipper length is **200.92 mm**.

Upper two lines of code work and the rest do not, giving warnings that
‘argument is not numeric or logical: returning NA’.

``` r
as.numeric(created_data %>% pull(above_zero))
as.numeric(created_data %>% pull(character_value))
as.numeric(created_data %>% pull(category))

# try mean again
mean(as.numeric(created_data %>% pull(character_value)))
mean(as.numeric(created_data %>% pull(category)))
```

‘as.numeric’ function modify the type of those columns into numeric,
which gives 0 or 1 to boolean type, numeric value to characters, 123 to
different factor levels, and thus they could be calculated by ‘mean’ and
it works.
